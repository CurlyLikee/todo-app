# Список справ - Вебзастосунок TODO App

Інтерактивний вебзастосунок для керування щоденними справами зі збереженням стану та відстеженням кількості завдань. Роботу виконано в межах Лабораторної роботи №18 з навчальної дисципліни "Програмування: Веб-програмування".

## Сторінка на GitHub Pages
[Переглянути сайт онлайн](https://curlylikee.github.io/todo-app/)

## Функціональні можливості

Застосунок реалізує повний цикл роботи зі списком справ:

1. **Додавання справ**:
   - Створення нового завдання через модальне вікно введення.
   - Автоматичне додавання справи до загального списку з унікальним ідентифікатором.

2. **Відмітка про виконання та оновлення статусу**:
   - Інтерактивний чекбокс для перемикання стану завдання.
   - Візуальне виділення виконаної справи зеленим кольором та перекресленим текстом.

3. **Видалення та підрахунок**:
   - Кнопка видалення для швидкого вилучення справи зі списку.
   - Динамічний перерахунок загальної кількості справ та кількості невиконаних завдань у реальному часі.

4. **Збереження даних у Local Storage**:
   - Автоматична синхронізація списку справ у локальному сховищі браузера.
   - Відновлення всіх завдань та лічильників після перезавантаження або закриття сторінки.

## Технології
- HTML5 семантична розмітка сторінки.
- Bootstrap 5 стилізація компонентів, списку та кнопок.
- JavaScript робота з масивом об'єктів, методами map, filter, шаблонними рядками та Local Storage.
